# Review Gates

## Gate A — Plan
确认 Semantic Map / Edit Plan 的语义和包装密度，不渲染。

## Gate B — Shotbook + Assets
确认逐镜：
- primary visual job
- presentation mode
- inputs
- asset slots
- safe zones
- primary motion family/subtype
- camera / annotation / transition layers

Required 素材未就绪时不得进入最终执行。

## Gate C — Stable Frame Review
不先整片重渲。每个代表性镜头在主要入场完成后抽稳定帧，默认取该视觉beat的约72%。

优先覆盖不同结构的代表镜头，生成 contact sheet。

每帧必须人工/视觉模型检查：
- face safety
- subtitle clearance
- clipping/overlap
- density
- contrast/readability
- semantic fit
- evidence integrity

任一 blocking issue 不进入最终整片。

## Gate D — Render + QC
渲染成片后检查：
- 时间点是否卡语义
- 连续效果是否重复
- 镜头/版式节奏是否单调
- 素材是否正确绑定
- 音效是否干扰口播
- 是否偏离 Style Profile

失败则回到 Shotbook / Router / Generated Motion 的对应层修改，而不是无脑重做整片。
