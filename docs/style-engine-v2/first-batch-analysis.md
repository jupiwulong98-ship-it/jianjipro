# 第一批三视频分析结论

## 样本
- video-1.mp4 — 303.65s
- 从报告到PPT...mp4 — 192.07s
- 用AI轻松GET活人感配音...mp4 — 123.00s

## 分析方式
- 全片1fps扫描，覆盖完整619秒。
- 对关键动效段追加6fps微动效复核。
- 事件按“语义触发 -> 视觉类型 -> 布局 -> 动作 -> 证据”记录。
- 当前不把音频SFX精确名称写死，因为视觉扫描无法可靠证明具体音效。

## 最重要的发现
真正稳定的不是某个“炫酷动画”，而是一套导演决策：

1. 口播默认保持干净。
2. 出现结构变化时才用章节标题卡。
3. 出现2~6个并列短概念时，用累积标签。
4. 出现软件操作时，屏幕成为主画面，人物退到PIP。
5. 出现复杂产品逻辑时，用暗色舞台同时承载人物、截图、标签。
6. 出现具体工具名时，用Logo/关键词做实体锚点。
7. 出现结果和画质描述时，用真实结果B-roll证明。
8. 高密度视觉段结束后，会主动回到纯口播降低认知负担。

## 为什么要拆 Editorial Grammar / Visual Skin
样本1与样本3更接近同一视觉体系，样本2的皮肤略有不同，但三者剪辑决策逻辑高度一致。

如果不拆层，会错误学成：
“教程 = 黑色斜纹 + 黄色标签”。

正确应该是：
“教程 = 屏幕主画面 + 人物PIP + 必要步骤标注”，
而黑色斜纹、黄色标签只是一个可替换的Skin。
