# 对标视频输入规范

## 第一批建议
同一位博主先给 3~5 条，不要一上来混 10 个博主。

优先选择：
- 45 秒以上，最好 60~180 秒；
- 包装风格稳定；
- 画面不是纯素材混剪；
- 能看清字幕、人物、动效和 B-roll；
- 至少包含 3 种以上包装事件；
- 原始分辨率尽量 1080p；
- 最好无二次搬运水印。

## 每条视频要提取
- shot/cut
- caption event
- keyword emphasis
- camera punch/zoom
- graphic card
- diagram/data visualization
- image/video B-roll
- icon/sticker
- background treatment
- transition
- sound effect
- music behavior
- silence/pause
- visual density

## 每个事件必须记录
- start/end
- spoken text
- semantic role
- trigger evidence
- visual description
- motion description
- assets
- sound
- relationship to previous/next event
- confidence
