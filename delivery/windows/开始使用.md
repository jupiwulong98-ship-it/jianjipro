# jianjipro · Windows 客户交付包

版本：2026-10-01；源码基线：6bae085。此包不依赖私有 GitHub 仓库权限。

## 包里有什么

- jianjipro 的风格、语义规划、素材、镜头编排和质检技能。
- 108 张 TalkCraft 模板源码、配方及离线演示。
- 8 张已适配卡的 Remotion 分段透明 MOV 渲染工具；其他模板需适配后才能套入真实文案渲染。
- 项目审阅看板：查看镜头、模板和素材，提交意见，逐段确认。
- 虚构示例项目及渲染测试计划。没有作者的真实视频、真实项目截图或审阅记录。

## 首次安装

1. 安装 Node.js 22 或更新的受支持版本。官方下载：https://nodejs.org/
2. 把 ZIP 完整解压到本机普通文件夹；不要直接在压缩包内运行。
3. 双击 `安装依赖.cmd`。首次需要联网下载依赖。
4. 双击 `启动看板.cmd`。待服务显示启动成功，浏览器打开 http://127.0.0.1:5201/#review 。
5. 保留启动窗口。关闭窗口后，看板与意见保存服务停止。

仅查看模板和使用看板不需要 FFmpeg。渲染视频需安装 FFmpeg，确保终端能运行 `ffmpeg -version` 和 `ffprobe -version`。下载入口：https://ffmpeg.org/download.html 。Remotion 首次渲染会按需下载浏览器。

## 做自己的口播

在有 ChatCut 工具的 Codex 环境打开此文件夹，交给助手：

> 按 AGENTS.md 和 skills/style-engine 的流程处理我的实拍口播。先在 ChatCut 初剪，不用 Whisper，保留有用的临场补充。初剪与字幕确认后，再规划包装和素材，生成本项目的审阅看板；经我确认后分段渲染，预览满意再装配到 ChatCut 副本。每一步告诉我在做什么。

本仓库不会自动安装 Codex、ChatCut Desktop 或 ChatCut 连接工具。看板确认不会自动启动 AI 或修改视频；助手需读取意见文件并继续执行。

当前示例看板是固定配置，不是多项目管理应用。替换项目数据应由助手生成 `motion-library/src/review/project.json`，放好对应本地素材，再刷新看板。意见按项目 ID 保存在 `projects/<项目ID>/review.json`。

## 渲染测试

在 `motion-library` 文件夹打开终端：

```powershell
npm run talkcraft:resolve -- ../projects/talkcraft-integration-smoke/plan.json
npm run talkcraft:render -- ../projects/talkcraft-integration-smoke/render-test.json --stills
```

确认代表帧后，移除 `--stills` 可渲染透明 MOV。详细参数见 `motion-library/docs/talkcraft.md`。
