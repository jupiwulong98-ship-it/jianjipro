# Windows 交付准备

Windows 安装与启动模板。2026-10-01 已生成完整客户 ZIP，并通过 macOS 环境下的包内安装、构建、测试与完整性验证；Windows 实机仍待验收。

1. 安装 Node.js 22 或更新的受支持版本。
2. 完整解压 ZIP 后，双击“安装依赖.cmd”。首次安装需要联网。
3. 双击“启动看板.cmd”，按窗口提示打开本机网页。
4. 渲染透明视频另需 FFmpeg 和 ffprobe 在 PATH 中；Remotion 会按需要下载浏览器。
5. 实际 ChatCut 初剪与装配需要 ChatCut Desktop，以及有 ChatCut 工具的 Codex 环境。安装本仓库不会自动安装这些工具。

## 验证边界

本机 macOS 已验证看板、意见保存和构建；这两个 CMD 尚未在真实 Windows 上运行。交付前需在客户机器检查安装、看板、意见持久化、透明片段渲染和 ChatCut 合成。
