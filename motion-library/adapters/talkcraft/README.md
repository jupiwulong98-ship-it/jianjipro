# TalkCraft 适配卡

上游原件在 `../../vendor/talkcraft/`；这里存放从此前真实口播工程提取并继续参数化的制作版本。

每张卡保留上游动画结构，开放文案、素材及实际生效的参数。修改此处后，渲染缓存自动失效。卡片能力与限制见 `registry.json`。

原卡的 demo 只表示动画参考；它不代表已经替换成真实素材或适合当前人物位置。每条新视频都需要合成预览与用户审片。

上游许可及第三方声明随 `vendor/talkcraft/` 保存，适配代码也受对应许可约束。来源：Vincent Wei，https://github.com/Vincentwei1021/video-talkcraft。
