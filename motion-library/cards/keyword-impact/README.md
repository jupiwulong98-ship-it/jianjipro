# keyword-impact

当前版本：2.2.0。

模板负责左右分组排字，中间留出人物位置，快速滑入、停留、碎裂退场。`text` 保存完整文案，`splitAt` 指定语义分组位置（0 自动分半），`centerGap` 控制留空，`textY` 控制高度。字体根据两侧可用宽度自适应；例如“剪辑自由”分为“剪辑 / 自由”。

人像抠图不是本模板能力。只有需要人物轮廓进一步遮挡字边缘时，才独立使用时间线抠像前景；没有抠图也应能看见左右文字与中央空位。不能用连续大字加抠图替代模板本身的左右留空布局。

以参考视频开头约 0.2 秒滑入和约 1.5–1.7 秒碎裂退出为依据；不同长度实例把退出安排在结尾约 0.35 秒。碎裂为文字切片近似，不宣称逐像素复刻。旧版本保留。
