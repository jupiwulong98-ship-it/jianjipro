# Codex 默认执行：JIANJIPRO Studio V2

当前新项目使用 studio-v2/，先读这里的 README.md。旧 motion-library、TalkCraft、108卡、style engine 仅作历史参考，不在新片的决策或渲染必经路径。

按人的剪辑师真实工作思维执行：

1. 听完口播、ChatCut初剪、准确字词时间，保留有效气口；不要以写稿时间猜时间轴。
2. 全片一次性导演规划：观众此刻看什么、事实哪里需要证据、人物什么时候最自然、声音如何收放、哪些观点需要转场；不能见字幕就自动生成知识卡。
3. 自己在允许的账号与资源内获取真实 Logo、网页截图、必要的实际录屏；保留来源、采集时间、内容真实性。只有静态证据时不强造录屏。
4. 生成项目 studio/plan.json 并调用 preflight；让用户打开一张整片可视化工作台确认 **真实素材** 和 **整片构图方向**，可以退回修改；这一阶段不要求完成所有复杂特效。
5. 两项认可后，自动从头至尾制作；内部按任意片段做缓存无所谓，**不准每10秒要求用户确认**。使用 HyperFrames 等实际代码重新设计动画，复用个人风格语言而不固定模板。声音必须按语义配合、留白，不能后期盲目逐句加音效。
6. 同一时间轴装配全部字幕、真实界面、动态、转场、背景音乐和音效；整片检查，不把帧数/音轨存在等同视觉审美与连续听音通过。能够自动定位和修复的问题先修后重渲，不会的真实标记待用户最后看成片。
7. 最后仅交付一次整条视频，用户反馈后形成正/反案例。不得把AI自己选的参数自动提升为用户确定的风格参数。

此目录目前已有真实素材预审和FFmpeg基础制作程序，但未自动接入浏览器采集、ChatCut和HyperFrames专业动效，也未做真的人耳/人眼审片。这些步骤需要你调用实际可用的工具完成；不能把manifest写完等同于剪辑完成。
