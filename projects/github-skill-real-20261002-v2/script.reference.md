### 口播正文

我之前分享 Codex Skill 的那条视频，已经有 10 万多人看过了。
但其实，那几个 Skill 并不是我私藏的。
**它们基本都能在 GitHub 上找到。**
所以这期我不继续给你推荐 Skill 了。
我直接教你一个更有用的方法：
**以后缺什么工具，不用等别人分享，直接让 AI 去 GitHub 帮你找。**
比如你想找 Codex Skill、PPT 工具、视频处理工具，甚至一个非常具体的小功能，都可以用这个方法。
先说 GitHub 是什么。
你可以简单把它理解成一个巨大的项目仓库。
很多开发者会把自己做的 AI 工具、开源项目、学习资料，还有各种 Skill 放在这里。
而普通人其实不用学 GitHub 那么复杂。
**你只要会三件事：搜、看、复制链接。**
先打开 GitHub。
没有账号的话，点 Sign up，按照提示注册一个免费账号就可以。
接下来直接看顶部这个搜索框。
比如我要找 Codex 能用的 Skill，可以先搜：
**codex skills。**
想找 PPT 相关的，就搜：
**ppt skill。**
搜索之后，记得点 **Repositories**。
Repositories 就是“项目仓库”。
这里再教你一个很好用的小技巧。
如果你不是想找某一个工具，而是想一次找一批同类型的项目，可以在关键词前面加：
**awesome。**
比如：
**awesome codex skills。**
你经常会看到这种项目里面已经帮你整理好了几十个、甚至上百个同类工具。
看到感兴趣的，再点进去。
然后看搜索结果旁边这个 **Star**。
你可以简单把它理解成这个项目在 GitHub 上有多少人关注和收藏。
可以先按照 **Most stars** 排序，看看关注度比较高的项目。
但是注意：
**Star 多，只代表关注的人多，不代表一定适合你。**
所以真正重要的是点进去看 README。
README 就是这个项目的说明书。
英文不用全部看懂。
你先找三个东西：
**它是干什么的。**
**效果是什么样。**
**怎么安装和使用。**
看不懂直接让浏览器翻译，或者把项目链接丢给 AI。
确定这个项目可能有用之后，就复制浏览器地址栏里的 GitHub 链接。
然后直接发给 Codex：
“帮我检查一下这个项目能不能在 Codex 里使用，需要安装什么，有没有额外费用。如果可以，帮我安装好，再用一个简单例子告诉我怎么使用。”
到这里还没有结束。
**安装成功，不代表这个工具真的有用。**
一定要再让 Codex 实际跑一次。
比如这是一个 PPT Skill，你就把自己的一段内容丢进去，让它真的生成一份 PPT。
这是一个视频工具，就让它真的处理一次你自己的视频。
**跑得出来，而且结果符合你的需求，这个工具才真正属于你。**
所以以后再找 AI 工具，记住这个流程：
**先搜需求，找到项目，看 README，复制链接，再交给 Codex 检查、安装和实测。**
学会这个之后，你就不用天天等别人告诉你：
“最近又出了什么新 Skill。”
你完全可以自己去找。
