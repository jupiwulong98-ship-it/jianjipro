# 前20秒动效对比素材

旧版仍在：上一版自绘的亮青色数字、文件夹、工具图标、搜索路径、时钟断线。当前版使用已确认的五种现成动效，并按人物位置和逐字时间适配。

本目录保存两版完整视频、12张1920×1080原始截图、6张带旧版/新版标题的对比图，以及一条左右同帧对照视频和对比页。两个MP4的内容哈希与原预览记录一致，解码音轨完全一致。时间以两份本地20秒参考渲染为准，30fps；不是ChatCut原生导出。源文件及哈希在source-manifest.json。

## 口播组织建议

1. 先放旧版和新版，让观众看到同一句话的差异。
2. 说自己的真实感受：旧版图形、颜色和阴影的存在感偏强，想让观看更轻松。
3. 用三组变化解释：数字的层级、图标改成文字替换、示意图改成提前打码的真实页面。
4. 交代过程：先读取剪后的逐字稿和时间，逐段确定画面作用，再找合适模板；先做20秒看效果，通过后装到时间线。
5. 保留审美判断边界：“我觉得这样更舒服”是感受；模板来源、文字替换和素材变化是可以直接验证的事实。

## 避免讲错

- 旧版已经有0到10万+的数字，不能说新版才首次加上数字。
- 旧版文件夹和时钟本来就在解释语义，不能说旧版全部只是复述文案。
- 新版仍然有文字；改进在于词的替换、层级、时间和注意力安排，不能简单归结为“少字”。
- 本次实际使用五种模板，不宣称108种模板全都经过本片测试。
- 搜索页是资源入口概览，不证明某个工具真的运行成功。
- 视频展示素材不出现网址、仓库地址、具体Skill名称或来源脚注；这些保留在内部记录。
- 三组前后对比.png适合一眼比较风格；说明动态变化时仍应播放完整20秒或相应片段。左右对照视频comparison-20s.mp4只有一份原口播，原始before.mp4 / after.mp4仍保留。
