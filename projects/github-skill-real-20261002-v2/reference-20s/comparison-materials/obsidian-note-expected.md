### 口播正文

你看这两个画面，同样一段口播，动效前后是这样的。

左边是之前的，右边是现在的。
我自己更喜欢现在这版。
之前那些亮青色、黑色底板，还有一堆图标，看起来有点塑料感。
这次我就拿前20秒，重新做了一遍。

我先让AI拿到剪辑后的完整逐字稿，还有每个字词在时间线上的位置。
接着，把每一段话准备怎么呈现，放进工作台的表格里。
我能直接看到原话、画面怎么变化，再去改。

这里我给它定了一个要求：画面要让观众更容易听懂这一句。

比如我说“不是私藏”，原来是文件夹开锁，里面放着几个工具图标。
现在就划掉“私藏”，同一个位置换成“公开可找”。
我觉得这个转折更直接。

说到找方法，原来有工具清单、搜索线、放大镜。
现在就把“推荐清单”删掉，重新打出“找方法”。
画面里的变化，跟我这句话的变化放在一起。

实际制作时，我让AI优先找现成的动效模板，再根据这句话的内容和时间来改。
数字计数、划线替换、打字改口，都有动画可以复用。

还有一处很直观。
这个数字，两版都是从0到10万多。
我把亮青色和阴影收掉，改成黑色数字，只留一点强调色。

出现什么，什么时候变，什么时候停下来，这些都要提前讲清楚。

我也没直接重做整条。
先看这20秒，觉得效果可以了，再放回剪辑时间线。

你也可以拿自己的一小段口播试一下。
先写清楚每一段想让人看懂什么，再让AI去做那个画面。
