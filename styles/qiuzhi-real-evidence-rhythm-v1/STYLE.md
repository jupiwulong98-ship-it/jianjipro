# 秋芝《豆包大升级》参考剪辑语言：真实证据与声画节奏

来源：my-super-experiments 仓库 03（0–10秒分析）与 19（全片章卡/声音拆解）。对标源视频使用 Git LFS；这里只归纳已有分析证据，不复制原片的音乐、素材或特定品牌视觉。**本文件是候选风格，不是用户已全部确认的固定规范。**

## 实际拆解的观察

- 0–1.2秒：人物后有大字，人物前景仍在最前；1.2–2.067秒回到干净人物，只留字幕。
- 2.067–2.9秒：产品图标先入、名称后出现；不是全套知识卡同时进场。
- 2.9–4.267秒：短促的大字放大/回落；文字与真实人物有遮挡关系。
- 4.267–8.333秒：数秒人物口播，没有额外知识卡；留白是刻意的节奏。
- 8.333–10秒：正常字幕先到，再出现独立的弧形重点文字，图层动作错开。
- 全片有真实UI、工作场景、案例验证、限制条件与段落回收。情境示意帮助理解，真实截图/录屏负责证据，不能混淆。
- 约0:21进入正文；约1:48.73、2:40.53、4:32.77、5:46.27切入不同实测章卡；部分章卡末尾有低电平/近静音窗口。测量不能证明音效具体来源或音色。

## 可迁移的导演规则

1. 真人始终承担叙述，只在必要的新信息、视觉证据、操作、观点边界时改变焦点。
2. 讲产品、功能、价格、按钮、结果时，先准备真实软件截图、Logo、实际录屏；不能用无关蓝背景/箭头/重复知识卡填空。
3. 实图先让观众认出界面，再局部放大/指向；文字和目标区域完整可读后再离场。
4. 声音跟真正出现/改变的画面或语义重音；同组比较、纠错、章节启动要有不同强度，音效之后可以保持安静。
5. 统一字体层级、安全区、已验证的颜色/圆角/缓动等视觉语法，不固定每个窗口的数量、位置与使用秒数。
6. 全片先确定强弱、证据位置和声音节奏；内部可以批量按镜头渲染，但**不逐10秒让人确认**。

## 不要误读

不能把紫色拍摄灯光当固定包装背景，不能把某个10秒的入场时长套到全部视频，不能默认将对标提取的背景伴奏用于商业内容。技术pass不等于用户认可，认可标签必须靠真实最终体验。
