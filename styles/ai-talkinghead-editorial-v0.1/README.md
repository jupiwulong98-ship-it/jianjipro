# AI Talking-head Editorial v0.1

这是三条样本提炼出的**候选风格**，不是最终锁死版本。

## 关键判断

三条视频的剪辑“语法”高度一致，但视觉皮肤存在差异。因此本风格拆成：

- **Editorial Grammar**：什么语义该触发什么类型的包装。
- **Visual Skin**：包装的颜色、字体、PIP、卡片、网格、标签长相。

这一步非常重要。以后可以保留成熟的剪辑决策，同时替换成自己的品牌视觉，而不是做1:1复制。

## 当前最稳定的规则

1. 章节切换 -> 强标题。
2. 2~6个并列短概念 -> 标签逐项累积。
3. 软件操作/产品演示 -> 屏幕变主画面，人物缩成PIP。
4. 复杂产品说明 -> 暗色网格舞台承载人物+大屏+能力标签。
5. 首次提工具/模型/概念 -> Logo或大关键词提示。
6. 高密度视觉段之后 -> 主动回到干净口播。
7. B-roll优先承担“证据”而不是纯装饰。

## 暂未固化

- 精确BGM规则。
- 每个动效的具体SFX。
- 单个标签的精确弹性曲线/easing。
- 章节标题卡的唯一视觉皮肤。

这些必须在音频复核和模板复刻阶段继续补。
